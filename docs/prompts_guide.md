# 提示词指南

## 什么是提示词？

提示词是告诉AI如何生成内容的指令。好的提示词能让AI生成更符合预期的内容。

## StoryForge提示词结构

```yaml
name: "提示词名称"
type: "comic"  # comic / drama
version: "1.0"

# 提示词模板
template: |
  你是一个专业的漫画脚本作家。
  
  ## 任务
  请根据以下信息，生成一个完整的漫画脚本。
  
  ## 输入信息
  - 主题: {theme}
  - 风格: {style}
  
  ## 输出格式
  [定义输出格式]
  
  请开始创作：

# 预设参数
defaults:
  style: "日常轻松"
  audience: "青少年"
  pages: 4
```

## 参数说明

| 参数 | 说明 | 必填 |
|------|------|------|
| `{theme}` | 主题 | ✅ |
| `{style}` | 风格 | ❌ |
| `{audience}` | 目标读者 | ❌ |
| `{pages}` | 页数/集数 | ❌ |

## 自定义提示词

### 步骤1: 创建提示词文件

在 `prompts/` 目录创建新的 YAML 文件，如 `my_prompt.yaml`。

### 步骤2: 编写提示词模板

```yaml
name: "我的自定义提示词"
type: "comic"
template: |
  你是一个专业的漫画脚本作家。
  
  主题: {theme}
  风格: {style}
  
  请生成一个4页的漫画脚本...
```

### 步骤3: 使用自定义提示词

```bash
python -m storyforge custom --prompt prompts/my_prompt.yaml --theme "校园日常"
```

## 提示词技巧

### 1. 明确任务
告诉AI你要它做什么，是写漫画脚本还是短剧剧本。

### 2. 定义输出格式
明确告诉AI你想要什么格式的输出，这样生成的内容更容易使用。

### 3. 提供示例
如果可能，在提示词中提供示例，让AI知道你想要什么风格。

### 4. 设置约束
定义限制条件，如页数、风格、目标读者等。

### 5. 迭代优化
根据生成结果，不断调整提示词，直到满意为止。
